# Supported Developer Domains

The Developer Knowledge MCP server and REST API index official public documentation across the following domains:

- **Google Cloud and Infrastructure**:
  - `docs.cloud.google.com`
  - `cloud.google.com`
  - `docs.apigee.com`
  - `firebase.google.com`
- **AI and Machine Learning**:
  - `ai.google.dev`
  - `adk.dev`
  - `antigravity.google`
  - `geminicli.com`
  - `www.tensorflow.org`
- **Mobile, Web, and Client Platforms**:
  - `developer.android.com`
  - `docs.flutter.dev`
  - `dart.dev`
  - `developer.chrome.com`
  - `web.dev`
- **Languages, Tools, and Ecosystems**:
  - `go.dev`
  - `developers.google.com`
  - `developers.home.google.com`
  - `mapsplatform.google.com`
  - `fuchsia.dev`

For the live index scope, see the [Corpus Reference](https://developers.google.com/knowledge/reference/corpus-reference).
