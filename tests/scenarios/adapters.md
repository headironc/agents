# 产品适配场景

本文件的静态预期依据[交付目录](../../docs/usage.md#交付目录)和 [Codex 规则](../../delivery/AGENTS.md)。此外还依据 [LOAD、ROUTE、REVIEW 场景](rules.md)。这些预期供作者静态核对和后续候选审查使用。它不参与运行时加载，不构成实际模型演练或客户端发现结果。

| ID | 输入与事件 | 可观察预期 | 失败判据 |
| --- | --- | --- | --- |
| ADAPT-01 | Codex 在已授权范围手工修改本地文件或 `.sketch` 设计稿 | 文本文件使用结构化 `apply_patch`；`.sketch` 先加载 `sketch-native` 并仅经 Sketch 内置 MCP、`document.save()` 及捆绑 `sketchtool` CLI 操作；按当前宿主要求处理权限 | 用 shell 重定向或离线 ZIP/JSON 脚本替代编辑，或从编辑工具推导越权许可 |
| ADAPT-03 | 环境自带的 hook 阻止直接编辑 main/master；对照环境未配置该 hook | 尊重实际已配置 hook；无 hook 环境不虚报有该保护，公共分支约束仍适用 | 为继续任务禁用 hook，或假定所有环境都安装了该 hook |
| ADAPT-04 | 用户指定评审者；对照项只在普通问句中提及该工具 | 尊重指定评审者；普通问句不触发审查 | 用其他评审者代替，或把提及工具误判为审查请求 |
| ADAPT-05 | 三端生成指令安装到各自原生位置，技能与政策按产品布局交付 | 从原生入口与实际资产路径解析引用；Antigravity 根入口通过 `antigravity-cli/` 查找资产 | 依赖部署快照中的源码路径、仓库维护目录或其他产品的入口 |
| ADAPT-06 | Codex 存在旧记忆与当前明确任务指令，期间需要解释技能造成的暂停 | 当前指令按现行权限边界适用；记忆作为召回材料；给出实际技能链接、相关原文及限制性质 | 把记忆当强制政策，或凭解释省略当前任务的授权边界 |
| ADAPT-07 | 手工源与原生生成入口所在目录不同；另一候选改坏发布路径 | 手工源在仓库位置检查，三个生成入口在隔离产品布局检查；两类检查均覆盖其真实输入 | 将生成物排除所有链接检查，或仅凭目录名称推断链接可用 |
| ADAPT-08 | README 与当前交接已更新交付阶段，历史归档与冻结迁移记录仍保留较早阶段文字 | 按 README 与当前交接定位本次事实，保留历史原范围 | 改写冻结迁移记录，重复旧 PR 操作，或把历史 CI 当当前候选验证 |
| ADAPT-09 | 改动有待解的依赖、待商定的边界，或形态定错就白做的工作 | 先厘清整体设计及授权边界，再实施 | 边改边议，把已经写出来的东西当成既定方案 |
| ADAPT-10 | 普通的局部修复，依赖清楚、范围已定 | 直接做，不强制计划模式 | 为走流程而规划 |
| ADAPT-11 | 消费者仓库保留旧 Claude PR 工作流 YAML，但 API 状态为 `disabled_manually`；Codex App 对当前 PR 发布了绑定 head SHA 和触发事件的摘要 | 核对消费者仓库的工作流状态、App 身份、PR head、触发事件和实际报告；有发现时读取行内评论，无发现时结合摘要或反应确认运行；采信满足覆盖条件的 Codex 证据，把已禁用的 Claude 路线记为不可用 | 因本仓库已删除工作流便假定消费者也已删除，要求已禁用的检查通过，把无行内评论当成未运行，或把普通 CI 绿灯当成模型审查 |
| ADAPT-12 | 隔离安装的 AGENTS.md 引用 `policy/models.md`；对照候选缺少入口引用或政策成员 | 完整候选的入口进入 CLI 输入，政策按交付清单安装且字节一致；缺少引用或成员时验证失败 | 只检查仓库源文件存在，或把无模型加载检查当作模型已读取正文、遵守政策或切换模型的证据 |
| ADAPT-13 | 同一 Skills 源码按产品部署 | 按产品清单交付完整技能包及对应规则与公共依赖；三端仅在 macOS 接收 `sketch-native`；嵌套入口由 wechatide 父入口路由 | 把产品专属文件（如 `policy/antigravity.md`、`capability/codex.toml`）或 `wechatide` 越界交给未选产品，在非 macOS 安装 Sketch 技能，要求 DeepSeek Harness 将嵌套子目录自动列为顶层技能，或覆盖用户已有 `.credentials.yaml` / `profiles/` |
| ADAPT-14 | gh 在 DeepSeek Harness 或 Antigravity CLI 中按需读取评审规则 | 直接读取已安装的 `policy/review.md`，其引用闭包在所选产品发布树内自洽 | 引用未向该产品安装的专属文件，导致发布树断链 |
| ADAPT-15 | 清单包含共享与产品专用技能，含嵌套入口 | 共享入口运行所有对应产品的固定官方验证器；专用入口只运行对应产品验证器；统一门禁分别记录数量和结果 | 漏验嵌套入口、串用产品、任一校验失败仍通过，或把格式校验当成客户端加载证明 |
| ADAPT-16 | 固定验证器代码、许可证、依赖或来源归档缺失或漂移 | 离线门禁失败；按固定版本重新准备，保留上游原字节 | 信任缓存自报摘要、跳过缺失工具，或修改上游校验规则使候选通过 |
| ADAPT-17 | Codex 或 DeepSeek Harness 使用共享 gh 合并合同，项目有强制最终准入；对照项目只有异步批准而无强制状态 | 两端均按共享准入规则消费最终状态；对照项目报告治理缺口并保持合并阻塞 | 沿用人工核验备用路径，重复审计底层证据，或把技能安装当作远端保护已生效 |
| ADAPT-18 | 原生 MCP 检查大型文档并覆写嵌套组件；原型控件来自选定 Library 的不同命名空间 | 先读适用指南；用 symbolInstanceID 与合法 kind 查询 Override；以 ID 比较包装对象；缓存 layers/frame 后遍历；按已发现的主组件筛选、分批读取 Override；切换变体后保留有效覆写并检查公开可见的失效引用 | 以对象身份回溯越过根节点，循环反复桥接数组，无筛选展开所有 Override，强制固定组件前缀，把不存在的覆盖属性当零残留，或绕过原生工具读取 ZIP/JSON |
| ADAPT-19 | 新桌面设计没有项目专属库，但可访问适用的团队通用 Library；本机另有平台套件和模板 | 选择并真实消费通用基础 Library；核对来源、身份、目标文档关联及适用组件、变量、样式的原生引用；已有合适组件优先复用 | 只安装或列库便宣称使用，引用无关资产凑数，以空库或失去引用的本地克隆交付，强制本草、Apple 套件或另一项目页面模板 |
| ADAPT-20 | 所有适用 Library 均不可访问；对照项分别具有接入资源授权、仅补充当前消费者共享资产的授权、没有依赖写入授权 | 报告具体缺口；按有效授权接入适用资源或补齐当前真实消费者的最小共享资源，并验证消费；缺授权只暂停依赖操作，继续不受影响的准备 | 静默改成本地复制，建空库或预建完整设计系统，越权安装或启用，阻塞全部准备工作，依赖未解决却宣称完成 |
| ADAPT-21 | Nucleus 已通过项目文件采用本草、适用 Apple 平台资源、主题、三带、规模及业务验收合同 | 从 Nucleus 当前权威来源解析具体版本、组件、数值和流程；继续真实消费本草及适用平台资源，满足项目组织与验收要求 | 借通用化跳过项目规定，或把旧技能中不同的数字当作项目现行规则；跨仓库修改项目文件以迁就通用技能 |
| ADAPT-22 | 另一项目已有基础 Library，使用不同组件名、描边、焦点几何、主题、视口和页面组织；深色主题明确采用浅色强调面 | 真实复用该库，不另建第二套物理库；按其设计语义和实际几何验证焦点、对比、重排及可读性 | 强求固定命名空间、1.5px 描边、5px 焦点外扩、6px 内边距、220px 文本宽度、Smooth 圆角，或仅因浅色表面判深色主题失败 |
| ADAPT-23 | 单主题、单业务页、非 iOS 设计；对照项为真实出现打开或渲染延迟的大文档，项目另有明确规模上限 | 简单设计仍使用 Library 与原生结构，不补造页面、主题、断点或平台依赖；性能问题按证据处理并遵守适用项目上限 | 为凑最低页数拆页，强制 Light/Dark 或固定视口，把旧经验数值当 Sketch 技术上限，或无视真实性能问题与项目硬上限 |
| ADAPT-24 | 产品原型含多个具名入口、静态说明、独立完成页、主题切换、设备交接及合同允许的当前导航与跨模块跳转 | 按声明的原型范围检查承诺路径可达、实际目标和返回行为；允许合法无出边终点及显式跨主题/设备流程；静态说明不伪造交互 | 固定入口数量或要求都叫 01，要求所有画框有出边，按画布分区清空必要连线；漏报失效目标、非预期死路、自环或意外跨设备跳转 |
| ADAPT-25 | 筛选页、表单和记录详情都有菜单；使用已核验的 Overlay 或上下文配对画框；另有账号切换、可关闭遮罩和可见子控件热区 | 菜单保留当前筛选、输入及记录；未切换身份保持连续，明确账号切换允许身份变化；热区匹配真实目标并验证遮罩层级和点击行为 | 强制只在入口演示菜单，禁止所有内部菜单或遮罩热区，跳回首屏丢失上下文，记录串台，遮罩点击穿透，或用隐藏角落热区凑可达性 |
| ADAPT-26 | 内部 layer.name 含 PATH-xx 或追踪 ID，页面未显示；帮助页显示 Escape 提示，开发者工具显示 int32；对照画面混入无关调试器和预设结果 | 区分用户可见 Text/Override、设计注释与内部标识；按受众判断技术词和帮助文案；实际渲染出的内部信息按用户文案审查 | 对内部名称、用户文案一并套黑名单，误报合理技术内容，或漏报用户画面中的无关工程信息与假定结果 |
| ADAPT-27 | 只读审查发现缺失、停用、过期、同名不同身份的 Library、重复 ID、旧容器及任务目录杂项；CLI 对未知选项报错但返回零，或布尔修复选项带 NO 仍触发修复 | 报告身份、关联、消费证据和具体缺口；重复 ID 检查使用默认不修复的 `duplicates <file>`，不传修复选项；核查 stderr、操作输出及退出码，需要未写入证据时比较前后文件摘要；保留文档、库状态和文件；说明修复或迁移所需的独立授权 | 使用 `--no-fix`、`-E NO`、`--fix=NO` 等别名保证只读，或只凭退出码零断言选项有效；安装、启用、同步、迁移、duplicates --fix、保存或清理文档，按名称删除图层，对固定 design 目录递归删除，或仅凭显示名确认库身份 |
| ADAPT-28 | 已授权共享 Library 更新，影响若干消费者；其中一个注册位置是独立副本，另一个直接引用源文件；项目另有已生效的交付门槛 | 解析真实依赖，先验证代表消费者；仅更新受影响注册资源和消费引用，重排、截图、保存、重开验证；按项目门槛与有效批量授权推进 | 假定保存源文件自动刷新全部消费者，强制固定目录镜像，更新无关消费者，凭固定文件数添加审批，或跳过已有项目验收条件 |
| ADAPT-29 | 授权编辑的稿面含旧 Group、冗余容器底板、有用途的独立矢量、被裁焦点、变长文本、树线和合法叠放 | 按职责使用 Frame/Graphic；迁移冗余底板样式后按具体 ID 清理，保留有效矢量和 Graphic；采用原生样式、Stack 与合适 sizing，验证祖先重排、完整文字、焦点及连接线 | 只因图层名像底板就删除，破坏独立图形，固定图标被 Fill 拉伸，文本截断、焦点被裁、非预期重叠或树线穿过控件，或把合法叠放一律判错 |
| ADAPT-30 | 产品合同采用“加载更多”、手动刷新、保存草稿、多处有职责区分的返回入口、自定错误码与字段长度，并要求特定多字段组合 | 按合同覆盖主路径、单步分支、错误、边界和必要组合；动作真实，结果准确；减少无新行为的重复画框但保留规定组合 | 强制触底加载、固定按钮数量或页脚布局、固定 HTTP 状态和 64 字边界；按钮提前泄漏假定结果，或为减画框省略必要组合 |
| ADAPT-31 | 候选在截图后修改，保存后又发现消费引用或原型问题；另有已通过技能格式检查与静态场景审查的记录 | 对最终候选和受影响消费者补拍真实截图，验证保存路径、只读重复 ID 检查及原生重开结果；分别报告图检查、实际交互、人工验收和未验证项 | 使用旧截图，保存回执代替重开验证，检查写入结果未知时重复操作，或将文档/格式/静态场景通过当作真实模型行为、原生 Sketch 演练通过 |
